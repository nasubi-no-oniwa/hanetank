# ハネタンク

はね返る弾で撃ち合う、おもちゃの戦車バトル。スキルを振って、ブロックを置いて、2本先取。

## ファイルの中身

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目 |
| `js/config.js` | **調整はここ**（戦車・弾の速さ、スキルの段階ごとの数値、もらえるポイント、時間など） |
| `js/sim.js` | ルール本体（移動・反射・地雷・爆発・サドンデス・ステージ3つ） |
| `js/fx.js` | 3D表示とエフェクト（three.js） |
| `js/input.js` | 操作（スマホ・マウス・キーボード・コントローラー） |
| `js/cpu.js` | CPU（よわい／ふつう／つよい） |
| `js/net.js` | 合言葉オンライン（Firebase ＋ 直接通信） |
| `js/sound.js` | 効果音（その場で合成） |
| `js/firebase-config.js` | オンラインの接続先（さかさまドロップと同じFirebase） |
| `js/main.js` | 画面と試合の進行 |
| `lib/three.min.js` | 3D表示のライブラリ（three.js r158） |
| `database.rules.json` | Firebaseに貼る安全ルール（3つのゲーム共通） |

## スキル（各7段階、4が標準）

| スキル | ポイント | 1〜7の値 |
|---|---|---|
| たまの速さ | 上げても下げても1段1pt | ×0.55〜×1.8 |
| はねかえり | 上げるだけ（1が標準） | 1,1,2,2,3,3,4回 |
| 戦車の大きさ | 大きくすると1段+1pt、小さくすると1段1pt | ×0.6〜×1.45 |
| たまの大きさ | 上げても下げても1段1pt | ×0.5〜×2 |

もらえるポイント：1戦目6 → 2戦目9 → 3戦目12（毎回ふり直し・持ちこしなし）
